# EventFlow — REV8: tema e versão mobile

Esta revisão adiciona tema claro, escuro e automático e melhora o uso do sistema em celulares e tablets.

## Como usar o tema

- Dentro do sistema, use o botão de tema no rodapé da barra lateral, ao lado de **Sair**.
- Na tela de login, o botão aparece no canto superior direito.
- Cada clique alterna entre **Automático**, **Claro** e **Escuro**.
- A opção fica salva neste navegador. Em **Automático**, o EventFlow acompanha o tema configurado no aparelho.

## Melhorias para celular

- Menu lateral móvel aberto pelo botão no canto superior esquerdo.
- Formulários reorganizados em uma coluna.
- Botões e campos maiores para toque.
- Tabelas largas com rolagem horizontal.
- Logística com navegação horizontal entre os dias.
- Ajustes específicos em Chat, Estoque, Clientes, Equipe e Plataforma.

## Publicação

Substitua os arquivos do site pelos arquivos desta revisão e publique novamente. Depois, atualize o navegador com `Ctrl + F5` para descartar os arquivos antigos em cache.

Esta atualização não exige executar nenhum arquivo SQL.
