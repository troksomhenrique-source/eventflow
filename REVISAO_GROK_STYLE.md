
# EventFlow — revisão visual Grok Style

## O que foi ajustado
- Visual global aproximado do layout do workspace Grok (tema escuro, tipografia Space Grotesk + IBM Plex Sans, sidebar mais limpa).
- Navegação simplificada.
- Áreas mantidas somente com:
  - Som
  - Luz
  - Vídeo
  - Estrutura
  - Internet
  - Cenografia
  - Extras
  - Serviços
- Removidos da navegação principal:
  - Chat
  - Logística
  - Descritivo geral
  - Ordem de serviço
  - referências de Painel de LED / categorias antigas nos seletores principais.
- Categorias simplificadas em:
  - Estoque
  - Vendas
  - Especificações de equipamentos
  - Notas

## Observação
Os arquivos antigos não foram apagados do pacote, mas deixaram de aparecer na navegação principal para manter a operação mais limpa.
